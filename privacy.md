# Privacy Policy

Last updated: September 21, 2026

This Privacy Policy explains how information is handled in connection
with LiteLLM GUI Manager, its product website, software licensing,
purchases, and support.

## 1. About LiteLLM GUI Manager

LiteLLM GUI Manager is an independently developed third-party Windows
desktop application designed to help users configure and manage LiteLLM.

LiteLLM GUI Manager is not an official LiteLLM product.

LiteLLM GUI Manager does not bundle, host, provide, or resell any AI
model. It is a desktop management tool for LiteLLM and third-party
AI/API providers configured by the user.

## 2. Information Related to Purchases and Licensing

Depending on how you use the software, information handled may include:

-   email address used for purchase verification;
-   purchase or order information received from the payment provider;
-   license identifier;
-   Device ID used for machine-bound activation;
-   support information voluntarily provided by the user.

Device ID is used only for license activation, device association,
reactivation support, and related license administration.

## 3. Purchases and Payments

Purchases are processed by Paddle, which acts as the Merchant of Record
for eligible transactions.

Paddle may process information required for checkout, payment
processing, taxation, fraud prevention, order processing, refunds, and
legal compliance.

We do not ask customers to send payment card details directly to us.

## 4. License Activation

LiteLLM GUI Manager uses machine-bound license activation.

During activation, the application sends the information required to
verify the purchase and issue a license, which may include:

-   Device ID;
-   customer email address;
-   purchase verification information.

The license-signing private key is not included in the client
application.

## 5. Local Application Data

LiteLLM GUI Manager stores application data locally on your Windows
computer.

Depending on features used, local data may include:

-   application settings;
-   LiteLLM configuration files;
-   provider configuration;
-   API URLs;
-   environment variables;
-   API credentials entered by the user;
-   license information;
-   local usage statistics.

Application data may be stored under:

`%APPDATA%\LiteLLM_GUI_Manager\`

## 6. API Keys and Credentials

LiteLLM GUI Manager helps users manage API keys and credentials required
by LiteLLM and third-party providers.

The application does not intentionally transmit API keys, passwords,
tokens, or `.env` contents to developer-operated services for analytics
or credential collection.

Users remain responsible for protecting their own credentials.

## 7. Third-Party Services

LiteLLM GUI Manager may interact with third-party services including:

-   Paddle for payments;
-   LiteLLM-related services;
-   AI/API providers configured by the user;
-   GitHub Pages for the product website.

These services process information according to their own privacy
policies.

## 8. Support Communications

If you contact support, information may include:

-   email address;
-   license information;
-   purchase information;
-   Device ID when required;
-   diagnostic information voluntarily provided.

Please remove API keys, passwords, tokens, and other sensitive
information before sending support materials.

## 9. Data Security

Reasonable measures are used to protect information under our direct
control.

However, no software application or online service can guarantee
absolute security.
