# Privacy Policy

Last updated: August 18, 2026

This Privacy Policy explains how information is handled in connection with LiteLLM GUI Manager, its product website, software licensing, purchases, and support.

## 1. About LiteLLM GUI Manager

LiteLLM GUI Manager is an independently developed third-party Windows desktop application designed to help users configure and manage LiteLLM.

LiteLLM GUI Manager is not an official LiteLLM product.

LiteLLM GUI Manager does not bundle, host, provide, or resell any AI model. It is a desktop management tool for LiteLLM and for third-party AI/API providers configured by the user.

## 2. Information You May Provide to Us

Depending on how you interact with us, we may receive information such as:

- your email address;
- purchase or order information;
- license-related information;
- your Device ID when you provide it for machine-bound license activation, re-issuance, or support;
- information you voluntarily provide when contacting support.

Please do not send passwords, API keys, payment card numbers, `.env` files, or other unnecessary sensitive credentials to support.

## 3. Purchases and Payments

Purchases may be processed by Paddle, which acts as the Merchant of Record for eligible transactions.

Paddle may collect and process information required for:

We may receive limited customer and order information from Paddle where reasonably necessary to:

## 4. License Activation

LiteLLM GUI Manager currently uses machine-bound license activation.

For license issuance, re-issuance, support, or verification, information processed may include:

- Device ID;
- license identifier;
- license type;
- purchase or order reference;
- customer email address where necessary.

The Device ID is used for software licensing and device association.

The private license-signing key is not included in the LiteLLM GUI Manager client application.

## 5. Local Application Data

LiteLLM GUI Manager stores application data locally on your Windows computer.

Depending on the features you use, locally stored data may include:

- application settings;
- LiteLLM YAML configuration;
- provider configuration;
- BASE URLs;
- `.env` environment variables;
- API credentials entered by the user;
- license information;
- local usage statistics;
- logs;
- backup configuration.

Typical application data may be stored under:

`%APPDATA%\LiteLLM_GUI_Manager\`

Additional configuration files may be stored in directories selected or used by the application.

## 6. API Keys and Sensitive Credentials

LiteLLM GUI Manager includes features for managing API keys, tokens, environment variables, and other credentials used by LiteLLM or third-party providers.

When you use these features, LiteLLM GUI Manager may locally:

- read API keys;
- display masked credential values;
- edit credential values;
- write credentials to `.env` or configuration files;
- pass credentials to LiteLLM or other software when required for the configuration selected by the user.

LiteLLM GUI Manager does not intentionally transmit API keys, passwords, tokens, or `.env` file contents to servers operated by the LiteLLM GUI Manager developer for analytics, advertising, or credential collection.

However, credentials may be transmitted to LiteLLM or to third-party AI/API providers when required to use services that you configure.

For example, an API credential for a third-party provider may need to be used by LiteLLM when communicating with that provider.

The user remains responsible for protecting all API keys and other credentials.

## 7. Developer-Operated Services

Core local configuration management does not require a developer-operated cloud service for collecting your LiteLLM configuration or API credentials.

LiteLLM GUI Manager may nevertheless make network connections when you use features that require external services, such as:

- LiteLLM installation or component-related operations;
- model or provider information retrieval;
- third-party API access;
- version or resource retrieval;
- links or services explicitly requested by the user.

The existence of a network connection does not mean that API credentials are being collected by the LiteLLM GUI Manager developer.

## 8. Usage Statistics

If you enable or use the usage-statistics functionality, the current application design stores usage statistics locally.

Stored statistics may include information such as:

- provider;
- model;
- account or custom tag;
- token usage;
- cost;
- latency;
- success or failure state;
- request timing information.

The current usage-statistics design does not intentionally store:

- user prompts;
- model responses;
- API keys;
- authentication tokens;
- HTTP authorization headers.

Usage statistics remain local unless you choose to export, copy, back up, or otherwise transmit them.

## 9. Backups

LiteLLM GUI Manager may provide backup and restore functionality.

Sensitive configuration such as `.env` files should be handled carefully.

If you explicitly choose to include `.env` or other credential-containing files in a backup, the backup may contain:

- API keys;
- access tokens;
- provider credentials;
- other sensitive configuration.

Backup archives may not be encrypted.

You are responsible for securely storing, transferring, and deleting backup files that contain credentials.

## 10. LiteLLM and Third-Party AI Providers

LiteLLM GUI Manager helps users configure and manage LiteLLM.

LiteLLM and third-party AI/API providers are separate services and projects.

When you use LiteLLM to communicate with providers, information may be transmitted to those providers according to the configuration you selected.

Such information may include:

- prompts;
- model requests;
- model responses;
- account information;
- API credentials required for authentication;
- usage metadata.

The privacy practices of LiteLLM and third-party providers are governed by their own policies and terms.

LiteLLM GUI Manager does not control how those third parties process data.

You should review the privacy policy and terms of every provider you choose to use.

## 11. No Bundled AI Models

LiteLLM GUI Manager does not contain its own large language model and does not provide AI inference services itself.

The application is a management interface.

Any AI model accessed through LiteLLM is provided by a third-party service or by a model/runtime configured by the user, such as a locally operated model service.
